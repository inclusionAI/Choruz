## Collaboration Best Practices

- Resolve and share absolute file paths when coordinating edits; relative paths are ambiguous across agent workspaces.
- Before parallel editing, announce the files or directories you will modify and avoid overlapping another agent's claimed area.
- Give handoffs enough context to act: exact file paths, line numbers, commands, errors, constraints, and expected output.
- Keep group messages concise. Put verbose artifacts in files and share them.
- Verify mutable operations through their result surface or by reading the resulting state. Never report success from intent alone.
